# Contract reference

`KeyLeaseRegistry` — the Soroban escrow and accounting contract for KeyLease.
This page is generated by hand from `contracts/registry/src/`; treat the source
as authoritative.

- **Package:** `keylease-registry`
- **Wasm:** `target/wasm32v1-none/release/keylease_registry.wasm`
- **Network target:** Stellar (`wasm32v1-none`), `soroban-sdk 26`
- **Constants:** `SETTLE_GRACE_PERIOD_SECS = 86_400` (24 hours),
  `MAX_LEASE_DURATION_SECS = 2_592_000` (30 days)
- **Storage TTL:** `LEDGER_BUMP_THRESHOLD = 17_280`, `LEDGER_BUMP_EXTEND = 518_400`;
  leases extend to term + 24h grace + a 1-day buffer
- **On-chain metadata:** `name = KeyLeaseRegistry`, `version`,
  `description`, `repository`, embedded with `contractmeta!`

Every state-changing entry point calls `require_auth()` on the actor it
represents. Errors are returned as `Result<_, Error>`; codes are stable and never
renumbered. Every money-moving path persists its effect before calling the SEP-41
token (checks-effects-interactions).

## Administration

### `init`

```rust
pub fn init(env: Env, admin: Address) -> Result<(), Error>
```

Initialize the registry and appoint `admin`.

- **Caller / auth:** `admin` must authorize.
- **Trigger:** once, immediately after deploy.
- **Preconditions:** the registry must not already be initialized.
- **State:** sets `Admin`; extends instance TTL.
- **Events:** `registry_initialized { admin }`.
- **Errors:** `AlreadyInitialized`.
- **Notes:** the admin can only call `set_token` and `upgrade`. It cannot move
  user funds.

### `set_token`

```rust
pub fn set_token(env: Env, admin: Address, token: Address) -> Result<(), Error>
```

Point the registry at the SEP-41 token used for every deposit and payout.

- **Caller / auth:** `admin`, and `admin` must match the stored admin.
- **Trigger:** once at setup; again only to migrate the escrow asset.
- **State:** sets `Token`; extends instance TTL.
- **Events:** `escrow_token_set { admin, token }`.
- **Errors:** `NotInitialized`, `Unauthorized`.
- **Notes:** the native Stellar Asset Contract (SAC) is the usual value. Changing
  the token while leases are unsettled is a migration hazard — settle first.

### `upgrade`

```rust
pub fn upgrade(env: Env, admin: Address, new_wasm_hash: BytesN<32>) -> Result<(), Error>
```

Install a new registry Wasm through the Soroban deployer.

- **Caller / auth:** `admin`, and `admin` must match the stored admin.
- **Trigger:** a released bug fix or feature, after uploading the Wasm with
  `stellar contract upload`.
- **Effects:** `env.deployer().update_current_contract_wasm(new_wasm_hash)`.
- **Events:** `contract_upgraded { admin, new_wasm_hash }`.
- **Errors:** `NotInitialized`, `Unauthorized`.
- **Notes:** the contract id, storage and balances are preserved, so an upgrade
  must never change the `DataKey` layout or the meaning of stored values. See
  [Deployment](deployment.md#upgrading).

## Services

### `register_service`

```rust
pub fn register_service(
    env: Env,
    provider: Address,
    rate_per_call: i128,
    endpoint_hash: BytesN<32>,
) -> Result<u64, Error>
```

Publish a new leasable service.

- **Caller / auth:** `provider` must authorize.
- **Trigger:** when a provider lists an API or RPC endpoint.
- **Parameters:**
  - `rate_per_call` — price per metered call in token stroops; must be `> 0`.
  - `endpoint_hash` — 32-byte commitment to the off-chain descriptor.
- **Returns:** the new `service_id` (monotonic, starts at `1`).
- **State:** writes `Service(service_id)`, increments `ServiceCount`, extends
  instance TTL.
- **Events:** `service_registered { service_id, provider, rate_per_call, endpoint_hash }`.
- **Errors:** `InvalidRate`, `Overflow`.

### `set_service_active`

```rust
pub fn set_service_active(
    env: Env,
    provider: Address,
    service_id: u64,
    is_active: bool,
) -> Result<(), Error>
```

Pause or resume **new** leases for a service.

- **Caller / auth:** `provider`, and it must own the service.
- **Trigger:** maintenance, incident response, or retirement.
- **State:** updates `Service(service_id).is_active`.
- **Events:** `service_status_changed { service_id, provider, is_active }`.
- **Errors:** `ServiceNotFound`, `Unauthorized`.
- **Notes:** existing leases stay valid and settleable. Deactivation only blocks
  `create_lease`.

## Leases

### `create_lease`

```rust
pub fn create_lease(
    env: Env,
    consumer: Address,
    service_id: u64,
    requested_calls: u32,
    duration_secs: u64,
) -> Result<u64, Error>
```

Lock a deposit and mint a time-bound lease.

- **Caller / auth:** `consumer` must authorize.
- **Trigger:** a developer purchases metered access.
- **Preconditions:** `requested_calls > 0`, `0 < duration_secs ≤
  MAX_LEASE_DURATION_SECS`, the service exists and `is_active`, and `Token` is
  set.
- **Effects:** `transfer(consumer → contract, rate_per_call × requested_calls)`.
- **Returns:** the new `lease_id` (monotonic, starts at `1`).
- **State:** writes `Lease(lease_id)` with `expires_at = ledger.timestamp() +
  duration_secs` and a TTL covering the term plus grace; increments `LeaseCount`.
- **Events:** `lease_created { lease_id, service_id, consumer, allocated_calls, expires_at, locked_deposit }`.
- **Errors:** `InvalidCalls`, `InvalidDuration`, `DurationTooLong`,
  `ServiceNotFound`, `ServiceInactive`, `InvalidRate`, `TokenNotSet`, `Overflow`.

### `settle_lease`

```rust
pub fn settle_lease(
    env: Env,
    provider: Address,
    lease_id: u64,
    verified_calls: u32,
) -> Result<(), Error>
```

Pay the provider for verified calls and refund the remainder to the consumer.

- **Caller / auth:** `provider`, and it must own the lease's service.
- **Trigger:** at or after expiry, or as soon as every allocated call is consumed.
- **Preconditions:** lease exists, is not settled, `verified_calls ≤
  allocated_calls`, the caller owns the service, and the lease has expired **or**
  `verified_calls == allocated_calls`.
- **Effects:** persists `used_calls` and `settled = true` **first**, then calls
  `transfer(contract → provider, verified_calls × rate_per_call)` and
  `transfer(contract → consumer, locked_deposit − payout)`.
- **Events:** `lease_settled { lease_id, provider, verified_calls, payout, refund }`.
- **Errors:** `LeaseNotFound`, `LeaseAlreadySettled`, `InvalidCalls`,
  `Unauthorized`, `LeaseNotSettleable`, `TokenNotSet`, `Overflow`.
- **Notes:** zero-value transfers are skipped. Settling with
  `verified_calls = 0` is a legitimate way for a provider to refund an
  unusable lease. A re-entrant token sees `settled = true` and is rejected.

### `revoke_expired_lease`

```rust
pub fn revoke_expired_lease(
    env: Env,
    consumer: Address,
    lease_id: u64,
) -> Result<(), Error>
```

Reclaim the **full** deposit when the provider never settled.

- **Caller / auth:** `consumer`, and it must be the lease's consumer.
- **Trigger:** after `expires_at + SETTLE_GRACE_PERIOD_SECS`.
- **Effects:** persists `settled = true` first, then
  `transfer(contract → consumer, locked_deposit)`.
- **Events:** `lease_revoked { lease_id, consumer, refund }`.
- **Errors:** `LeaseNotFound`, `Unauthorized`, `LeaseAlreadySettled`,
  `LeaseNotExpired`, `RevokeWindowNotElapsed`, `TokenNotSet`, `Overflow`.
- **Notes:** this is the consumer's escape hatch, and the reason escrow is safe
  against an unresponsive provider.

## Read-only views

These require no authorization.

| View | Signature | Returns |
| --- | --- | --- |
| `get_admin` | `(env) -> Result<Address, Error>` | stored admin, else `NotInitialized` |
| `get_token` | `(env) -> Result<Address, Error>` | escrow token, else `TokenNotSet` |
| `version` | `(env) -> String` | version embedded by `contractmeta!` |
| `service_count` | `(env) -> u64` | total services ever registered |
| `lease_count` | `(env) -> u64` | total leases ever created |
| `get_service` | `(env, service_id: u64) -> Result<Service, Error>` | the `Service`, else `ServiceNotFound` |
| `get_lease` | `(env, lease_id: u64) -> Result<Lease, Error>` | the `Lease`, else `LeaseNotFound` |
| `lease_status` | `(env, lease_id: u64) -> Result<LeaseStatus, Error>` | derived status at current ledger time |
| `remaining_calls` | `(env, lease_id: u64) -> Result<u32, Error>` | calls left; `0` once settled **or** expired |
| `locked_balance` | `(env, lease_id: u64) -> Result<i128, Error>` | `locked_deposit`; `0` once settled |

> `remaining_calls` returns `0` as soon as the lease expires, even if calls were
> never consumed. A caller that wants the raw allotment should read
> `get_lease().allocated_calls`.

## Storage layout

```rust
pub enum DataKey {
    Admin,        // instance
    Token,        // instance
    ServiceCount, // instance
    LeaseCount,   // instance
    Service(u64), // persistent
    Lease(u64),   // persistent
}
```

`#[contracttype]` enums encode as a `SCV_VEC` whose first element is an
`SCV_SYMBOL` variant name — so `DataKey::Lease(7)` is the wire key
`Vec[Symbol("Lease"), u64(7)]`. This matters if you read contract data directly
with `getContractData`; see the [developer guide](developer-guide.md#reading-contract-state-and-events).

## Error codes

Codes are part of the ABI. New variants are **appended**; existing numbers are
never reused.

| Code | Variant | Meaning |
| --- | --- | --- |
| 1 | `AlreadyInitialized` | `init` called twice |
| 2 | `NotInitialized` | registry has no admin |
| 3 | `Unauthorized` | caller is not the required actor |
| 4 | `ServiceNotFound` | no service with that id |
| 5 | `ServiceInactive` | service is paused |
| 6 | `LeaseNotFound` | no lease with that id |
| 7 | `LeaseAlreadySettled` | lease already settled or revoked |
| 8 | `LeaseNotSettleable` | not expired and not fully consumed |
| 9 | `LeaseNotExpired` | `revoke` before expiry |
| 10 | `RevokeWindowNotElapsed` | `revoke` inside the 24h grace window |
| 11 | `InvalidCalls` | zero calls, or more than allocated |
| 12 | `InvalidDuration` | zero duration |
| 13 | `InvalidRate` | non-positive rate |
| 14 | `TokenNotSet` | escrow token not configured |
| 15 | `Overflow` | checked arithmetic failed |
| 16 | `DurationTooLong` | lease duration above `MAX_LEASE_DURATION_SECS` |

## Invoking with the Stellar CLI

```bash
# register a service
stellar contract invoke --id $REGISTRY --source-account provider --network testnet \
  -- register_service \
     --provider $PROVIDER \
     --rate_per_call 1000000 \
     --endpoint_hash 0707070707070707070707070707070707070707070707070707070707070707

# create a lease
stellar contract invoke --id $REGISTRY --source-account consumer --network testnet \
  -- create_lease \
     --consumer $CONSUMER \
     --service_id 1 \
     --requested_calls 500 \
     --duration_secs 3600

# settle
stellar contract invoke --id $REGISTRY --source-account provider --network testnet \
  -- settle_lease --provider $PROVIDER --lease_id 1 --verified_calls 320

# upgrade (after `stellar contract upload`)
stellar contract invoke --id $REGISTRY --source-account admin --network testnet \
  -- upgrade --admin $ADMIN --new_wasm_hash <64_HEX_CHARS>
```

## MockToken (test only)

`contracts/mock_token` implements a minimal SEP-41 surface — `init`, `mint`,
`transfer`, `transfer_from`, `approve`, `allowance`, `balance`, `decimals` (7),
`name`, `symbol`, `admin` — with an **unlimited mint**.

It exists so local sandboxes do not depend on a live SAC, but it must **never**
be deployed to a network holding value. The registry's own tests escrow against
the real Stellar Asset Contract (`register_stellar_asset_contract_v2`).
